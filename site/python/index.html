◆ Python · S3 client

Data in and out of s3.pe.gov.br, in Python.

Nine verbs that read and write DataFrames, dicts, text and files by extension, on a Rust core that signs, retries and verifies every transfer. pip install s3pe, two environment variables, done.

Built to be trusted with the data

A client that moves the files a pipeline depends on has one job: either the bytes arrived, or you hear about it. Everything here serves that.

🗂️

Formats by extension

.json → dict, .csv/.csv.gz/.tsv/.parquet/.xlsx → DataFrame, text files → str, anything else → bytes. format= overrides; extra arguments go to pandas.

🦀

A Rust core

Signing, retries and checks happen in the s3pe crate; the GIL is released during transfers. Wheels for Linux (x86_64, aarch64), macOS and Windows, Python 3.9 or later.

🔏

Signed the way Garage wants

AWS Signature V4 over the real SHA-256 of the body. No unsigned payloads, no aws-chunked trailers, path-style URLs.

🔁

Retries that know when to stop

Connection failures and HTTP 429/500/502/503/504: three tries, 1 s then 2 s. Never on other 4xx.

✅

Every byte accounted for

ETag against the local MD5 after a PUT; Content-Length and MD5 after a GET. Downloads land in a .s3pe-part file and are renamed when complete.

🧭

Typed exceptions

NotFoundError, AccessDeniedError, HttpError (with .status, .code), TransportError, ConfigError, IntegrityError, all under S3Error.

The nine verbs

Module-level verbs over a default client (s3pe.configure(bucket="iaempe") sets it), and the same verbs as methods of s3pe.Client.

VerbDoes
read_s3GET, decoded by extension or format=
write_s3PUT a DataFrame, dict, list, str, bytes, file-like or Path
download_s3GET to a file, streaming; refuses to overwrite unless asked
upload_s3PUT from a file, streaming
list_s3every S3Object under a prefix, all pages
exists_s3bool
head_s3S3Object or None: size, type, date, ETag
delete_s3idempotent
buckets_s3list of Bucket

A key is s3://bucket/key, or a bare key when the bucket is configured (S3PE_BUCKET or the client). Credentials: AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY; endpoint S3PE_ENDPOINT, default https://s3.pe.gov.br.

What happens in every call

The same six steps in the four editions.

01

Resolve and hash

s3://bucket/key or bucket plus key; SHA-256 for the signature, MD5 for the check.

02

Sign and send

SigV4 over host, date and payload hash; path-style, Content-Length, no chunked trailers.

03

Retry

Connection failures and 429/5xx, three tries, 1 s then 2 s. Other 4xx come straight back.

04

Verify and report

ETag and Content-Length checked; one line on stderr; typed errors otherwise.

Install & run

Python 3.9 or later; pandas and pyarrow only for tables. Changes between versions in the changelog.

$ pip install s3pe              # bytes, str, dict/list and files
$ pip install "s3pe[pandas]"     # also CSV, Parquet and Excel as DataFrames
# an explicit client
s3 = s3pe.Client(endpoint="http://127.0.0.1:9003",
                 bucket="iaempe",
                 access_key="GK…", secret_key="…")
s3.read("dados/metadata.json")
s3.write(df, "nota/icms.csv", index=False)
s3.download("dados/pe_municipios.geojson", "pe.geojson")
s3.upload("figura1.png", "nota/")
s3.head("etl/painel.parquet")      # S3Object or None

s3pe.quiet()                        # or S3PE_QUIET=1
# errors and formats
try:
    s3pe.read_s3("s3://iaempe/missing.json")
except s3pe.NotFoundError:
    ...
except s3pe.HttpError as e:
    print(e.status, e.code)

raw = s3pe.read_s3("x.csv", bucket="b", format="bytes")
df  = s3pe.read_s3("x.csv", bucket="b", sep=";", dtype=str)
s3pe.write_s3({"ok": True}, "s3://b/manifest.json")
s3pe.write_s3(df, "s3://b/series.csv.gz")   # gzipped on the way

Architecture

The Python package is a thin layer: formats and logging in Python, everything on the wire in the Rust crate through PyO3. R and Go reimplement the same specification; the four signers reproduce the AWS documentation vector. One repository, one version, one DESIGN.md.
